# JavaScript Examples

This folder contains small, self-contained JavaScript examples:

- `hello-world.js` — Node.js console hello world.
- `browser-dom.js` — DOM manipulation for the browser.
- `async-fetch.js` — `fetch` with async/await (works in modern Node or browser).
- `simple-server.js` — Minimal Node.js HTTP server (no external deps).

Run examples:

Node examples:

```
node js-examples/hello-world.js
node js-examples/async-fetch.js
node js-examples/simple-server.js
```

Browser example:

- Open `js-examples/browser-dom.html` in a browser (or include `browser-dom.js` in a page).
